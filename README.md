# FinanceTeleBot

A project hosted on GitHub.

## Overview

This repository contains the source code for the **FinanceTeleBot** project.
It is primarily developed using **Python**.

## Features

- Telegram Bot for financial analysis (gold prices, IHSG, Indonesian economy)
- Utilizes Groq for AI processing and Tavily for web search.

## Technologies Used

- **Primary Language**: Python
- Python (for dependencies)

## Setup and Installation

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Python 3.x
- pip (Python package installer)

### Installation

1. Clone the repo
   ```bash
   git clone https://github.com/Abelion512/FinanceTeleBot
   ```
2. Navigate to the project directory
   ```bash
   cd FinanceTeleBot
   ```
3. Install Python packages
   ```bash
   pip install -r requirements.txt
   ```

## Usage

To run the bot, you will need to set up environment variables for `TAVILY_API_KEY` and `GROQ_API_KEY`. Then run:
```bash
python bot.py
```
